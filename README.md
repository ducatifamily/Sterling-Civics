# Sterling Civics — Class of 2028
Student-led website concept by Arianna and Kristianna Sidwell. AI-assisted implementation from the student wireframe and supplied content.

## Preview
Run `python -m http.server 8000` from this folder, then open http://localhost:8000.

## GitHub and Render
Create a repository (private initially), upload the contents of this folder, and commit. On Render, create a Static Site connected to that repository. Build command: `echo "Static website ready"`; publish directory: `.`. Alternatively use the included render.yaml Blueprint. No dependencies or backend required.

## Maintenance
Each initiative has its own HTML file in projects/ with a financial update. Update verified earnings, dates, and details there. Update the calendar in fundraisers.html. Replace portrait placeholders in team.html with approved photos and descriptive alt text. The visual mark is an original placeholder, not the official school logo. Obtain permission before adding official branding or publishing student names/photos. Keep internal financial records and raw adversity logs outside the public repository. The public adversity log is summarized from the class log without personal criticism. Confirm spelling, dates, venue, beneficiary, and school approval before launch. Donation and ticket buttons are intentionally disabled until an approved external payment provider is available; do not collect payment details on this static site. Add an approved QR image and checkout link only after school authorization. No payments or bids are processed by this site.

## Source materials
Student-provided overview, original wireframe, class constitution and Pictures/Log for Civics. The constitution page summarizes the main tab. No private document links or raw student records are published. Photos are placeholders pending approved assets. The students should review and revise the implementation and document their own contributions for admissions purposes.
